# link_to_keywords

유튜브·인스타 링크 → 영상 대사 + 영상찾기 키워드(중국어 간체 / 일본어 / 영어 각 5개).
Gemini 무료 API 사용. 폰의 Claude 앱(Claude Code 클라우드 세션)에서 `/kw <링크>`로 실행.

- 화면 출력: 링크(첫 줄 단독 → 카톡에 붙이면 모바일에서 바로 눌림) + 키워드만, 링크(제품)별로 한 묶음씩 / 대사·제품명은 output/ 파일에 저장
- 유튜브: 링크를 Gemini에 직접 전달 (다운로드 없음)
- 인스타: 임시 다운로드 → Gemini 업로드 → 끝나면 로컬·Gemini 사본 모두 삭제
- 키워드 순서(언어별 고정): 제품명 / 현지 검색표현 / 사용 장면 / 효과 장면 / 핵심 특징
- 저장 후 파일을 다시 열어 대사·키워드 15개 존재 여부를 검증. 실패 시 종료코드 1
- 모델: 기본 `gemini-3.7-flash → gemini-3.5-flash-lite → gemini-2.5-flash` 순. 429(한도초과) 시 다음 모델로 자동 전환
- 테스트: `python -m pytest -q tools/link_to_keywords` (오프라인, 17개)
